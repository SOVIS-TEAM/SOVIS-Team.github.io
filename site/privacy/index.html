SoundVisualizer 개인정보처리방침

시행일: 2026년 11월 16일

SoundVisualizer(이하 "앱")는 팀 SOVIS가 만든 Android 앱입니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

1. 수집하는 정보

앱은 어떤 개인정보도 수집하지 않습니다.

  • 앱에는 인터넷 접속 권한이 없어, 어떤 정보도 개발자나 다른 곳으로 보내지 않습니다.
  • 회원가입, 광고, 사용 통계 도구가 없습니다.

2. 소리를 다루는 방법

  • 앱은 소리를 받아 화면 가장자리에 그리고 진동으로 알리는 데에만 씁니다.
  • 받은 소리는 기기 메모리에서만 처리하고, 녹음하거나 파일로 저장하지 않습니다.
  • 소리 종류를 판별하는 AI도 기기 안에서만 동작합니다.
  • 다른 앱의 소리를 받으려면 Android의 화면 녹화 동의가 필요합니다. 앱은 이 동의로 소리만 받고, 화면 영상은 받지 않습니다.

3. 기기에 저장되는 정보

  • 설정값: 모드, 색, 크기, 진동 등 앱 설정을 기기 안에 저장합니다. Android 기기 백업을 켜 두었다면 설정값이 사용자의 Google 계정 백업에 포함될 수 있습니다. 이 백업은 Google이 관리하며, 개발자는 볼 수 없습니다.
  • 개발자 기록: 숨겨진 개발자 모드에서 기록을 직접 켠 경우에만, AI가 판별한 결과(소리 종류 이름, 점수, 시각)를 앱 전용 폴더에 CSV 파일로 저장합니다. 소리 자체는 저장하지 않으며, 앱을 지우면 함께 지워집니다.

4. 권한과 쓰임

권한쓰임
마이크휴대폰에서 재생되는 소리와, 외부 사운드 모드에서 주변 소리를 받기 위해
화면 녹화 동의다른 앱이 재생하는 소리를 받기 위해 (화면 영상은 받지 않음)
다른 앱 위에 표시소리를 다른 앱 화면 위에 그리기 위해
알림실행 중임을 알리고, 잠금 화면에서 위협음을 알리기 위해
진동사용자가 켠 경우 소리를 진동으로 알리기 위해
화면 켜짐 유지잠금 화면 위협음 알림 때 화면을 잠깐 켜기 위해
포그라운드 서비스다른 앱을 쓰는 동안에도 소리를 계속 받기 위해

5. 문제 제보

  • 도움말 탭의 제보 버튼을 누르면, 사용자가 고른 GitHub 이슈 화면(브라우저)이나 메일 앱이 열립니다.
  • 앱 버전, Android 버전, 기기 모델, 앱 언어가 미리 채워집니다.
  • 보낼지는 사용자가 정합니다. 보낸 내용은 GitHub 또는 메일 서비스의 정책을 따르며, GitHub 이슈는 누구나 볼 수 있습니다.
